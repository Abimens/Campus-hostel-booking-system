# Software Requirements Specification (SRS)

## Campus Hostel Booking and Management System

# 1. Introduction

The Campus Hostel Booking and Management System is a web-based application designed to help students search for hostels, view room details, check room availability and submit booking requests. It will also help hostel managers manage rooms and student booking requests.

# 2. Problem Statement

Students often face difficulties finding suitable hostels, checking room availability and contacting hostel managers. This system aims to make the hostel booking process easier, faster and more organized.

# 3. Aim

To develop a web-based system that simplifies hostel searching, room availability checking and booking management.

# 4. Users of the System

- Students
- Hostel Managers
- Administrators

# 5. Functional Requirements

- Students can register and log in.
- Students can search for available hostels.
- Students can view hostel and room details.
- Students can submit booking requests.
- Hostel managers can manage rooms and availability.
- Hostel managers can approve or reject booking requests.
- Students can receive notifications about their booking status.

# 6. Non-Functional Requirements

- The system should be easy to use.
- The system should protect users' information.
- The system should respond quickly to user requests.
- The system should be accessible through a web browser.

# 7. Proposed Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- GitHub

# 8. External Service

The system will use an email notification service to notify students about booking confirmations, rejections and other booking updates.
